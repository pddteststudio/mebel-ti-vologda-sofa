# Мебель-Ти — концепция сайта-каталога диванов (Вологда)

Рабочая **независимая демонстрационная версия** сайта для мебельного салона из Вологды. Не является официальным сайтом компании. Подходит для предпросмотра и публикации демоверсии на Vercel.

## Как посмотреть

- Откройте `index.html` в браузере; навигация ведёт на остальные страницы.
- Для полностью самостоятельного предпросмотра каждой страницы без локального сервера: `preview-offline.html` (главная), `preview-catalog-offline.html`, `preview-fabrics-offline.html`, `preview-order-offline.html`, `preview-showrooms-offline.html`. В эти файлы встроены CSS, JS и все иллюстрации. Для переходов между разделами используйте обычные файлы без слова `preview-`.
- При желании запустите локально из корня проекта: `python -m http.server 8000` и откройте `http://localhost:8000/`.

## Публикация в Vercel

1. Распакуйте ZIP. Загрузите **содержимое папки** в GitHub, чтобы `index.html` лежал в корне репозитория.
2. Подключите репозиторий в Vercel: Add New → Project → Import.
3. Framework Preset: **Other**. Build Command не требуется, Output Directory по умолчанию / `.`.
4. Deploy. Готово.
5. Для *демонстрационной* публикации настроены `robots.txt` и `X-Robots-Tag: noindex`. Убирать эту защиту для официального запуска следует **только после согласования с правообладателем**.

## Что готово

- `index.html` — главная, категории, основные варианты, интерактивный пример смены оттенка, преимущества, салоны, CTA.
- `catalog.html` — 9 **условных** моделей-концепций с фильтрами по типу, максимальной ширине, местам, выбором оттенка, сортировкой, подробными окнами и подборкой.
- `fabrics.html` — референсы обивки (велюр, рогожка, шенилл, флок, экокожа). Можно выбрать тип ткани и перейти в конфигуратор с выбранным параметром.
- `order.html` — удобный подбор дивана: тип, желаемая ширина, 4 цвета, ткань, предпочтения. Живой демонстрационный эскиз и автоматическая генерация текста запроса для VK.
- `showrooms.html` — 3 известных из открытого справочника адреса, телефоны, справочные часы, переходы к маршрутам в Яндекс Картах.
- `assets/scenes/` — 36 **авторских SVG-иллюстраций**. Ни одна не выдаётся за реальный товар или фотографию фабрики.
- `previews/` — скриншоты и `qa.json` с автоматическими проверками.
- `СООБЩЕНИЕ_ДЛЯ_VK.txt` — первое сообщение для владельца после публикации.

## Важные ограничения

- **Все девять названий моделей, их габариты, посадочные места и иллюстрации демонстрационные.** Они придуманы для демонстрации структуры каталога и фильтрации. Ни один из примеров не представлен как подтверждённый диван «Мебель-Ти»; статус наличия не выдуман.
- **Реальные цены и актуальные остатки не подтверждены**, поэтому в карточках честно написано «Цена по запросу». Для официального запуска необходимо предоставить согласованный ассортимент, фото, размеры, цены и сведения о механизмах и материалах.
- Подборка диванов хранится только на устройстве пользователя в localStorage. Никакой информации о покупателе не собираем, не передаём и не храним на сервере.
- Кнопки «Скопировать заявку» **не отправляют заказ автоматически**: посетитель сам вставляет текст в сообщения VK. При недоступности буфера обмена текст заявки доступен для ручного копирования.
- Адреса, часы и телефоны салонов взяты из стороннего справочника. Перед официальным запуском необходимо их подтвердить у владельца.
- Домен `mebelti.com` существует, но его страницы и юридические данные указывают на **интернет-магазин в Новосибирске**, а не подтверждённую связь с данным салоном в Вологде. Мы **не** использовали чужой каталог, фото или реквизиты.
